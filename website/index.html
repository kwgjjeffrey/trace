Manual install & compatibility
curl -fsSL https://raw.githubusercontent.com/kwgjjeffrey/trace/main/setup/install.sh -o /tmp/agent-dev-install.sh
# Inspect the script, then:
sh /tmp/agent-dev-install.sh

Existing Trace paths, command names and release assets remain compatible. The suite ships as one versioned release. Restart the agent connection after installation or upgrade.
