# Security reporting

For credentials, unsafe archive extraction, source path escape or unintended data transmission, use the repository's GitHub Security Advisory private reporting if enabled. Otherwise contact the maintainer through the GitHub profile before sharing sensitive details. Do not post live tokens, trace prompt bodies or private source in public issues.

Alpha releases should be evaluated in an isolated environment. Only the latest release receives fixes. GitHub release manifests provide byte/hash/source integrity within the trusted repository; they are not independently signed. Provider configuration is explicit and separate from artifacts. Target regression scripts execute project code and carry the permissions of the user running them.
